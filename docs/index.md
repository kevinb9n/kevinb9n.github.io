## Work

After a few startups I worked at Google for two decades (2004 to 2024). In 2007 I founded the Java Core Libraries (now Java And Kotlin Ecosystem) team and stayed with it rest of my time there. Then I was introduced to the [layoff hammer](https://twitter.com/kevinb9n/status/1745890746350321818).

I went to Oracle in the Java Platform Group working on the language team (Amber and Valhalla) for about two years and am now self-unemployed.

### Things I did

Everything I've done is a collaboration.

I spearheaded the creation of [Guava](https://github.com/google/guava), wrote a bunch of the (most basic) libraries in it and continued to steward its API design for many years. I was also invokved to various degrees in making Guice, [AutoValue](https://github.com/google/auto/blob/master/value/userguide/index.md), [google-java-format](https://github.com/google/google-java-format), [Caliper](https://github.com/google/caliper), [Error Prone](https://errorprone.info/), [Truth](https://github.com/google/truth), [Flogger](https://github.com/google/flogger), and [jimfs](https://github.com/google/jimfs). I'm the primary author of the [Google Java Style Guide](https://google.github.io/styleguide/javaguide.html), which is probably the most-adopted Java style guide in the world I guess.

I was Google's representative to [JSR 330](https://jcp.org/en/jsr/detail?id=330), [JSR 335](https://jcp.org/en/jsr/detail?id=335), Project Valhalla, and Project Amber, for many years at Google before going to Oracle.
